# Historical exploration

`effr_modeling.ipynb` is preserved unchanged from the original project. It is an exploratory record, not the supported training entry point. Its paths, preprocessing and reported results may reflect the older leakage-prone workflow or unavailable intermediate files. It is not executed by CI and has no promise of clean-environment reproducibility.

Use the package command in the root README for the validated benchmark. See `docs/methodology.md` for the audit. Removed experimental scripts remain recoverable in Git history at commit `45f9f94`.
